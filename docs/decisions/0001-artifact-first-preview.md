# ADR 0001：预览采用“产物优先”模式

## 决策

在线预览不再通过 API 直接返回大量 mesh JSON，而是先把 CAD 源文件转换成预览产物，然后让前端通过 URL 加载。

当前产物类型：

- `.glb`

后续产物类型：

- `tileset.json`
- 3D Tiles 分块文件
- 压缩 mesh 文件

## 背景

原型项目曾经直接把解析后的点、边、三角面作为 JSON 返回给前端。这对小文件方便，但对大文件不成立：

- JSON 比二进制 mesh 大很多。
- 浏览器解析 JSON 会阻塞页面。
- API 响应过大容易失败。
- 没法做渐进加载和 LOD。

## 结果

采用产物优先后：

- API 响应保持很小。
- 前端可以用标准 3D 加载器。
- 后端可以复用已经生成的产物。
- 后续可以自然扩展到 3D Tiles。

代价：

- 需要后台任务系统。
- 需要管理产物生命周期。
- 需要设计存储、清理和权限策略。
